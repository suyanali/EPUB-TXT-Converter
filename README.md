# EPUB → TXT 轉換器

將 EPUB 電子書轉成 TXT 純文字檔，支援一次轉換多本書，也可以選擇簡體轉繁體。操作簡單，不需要註冊帳號。

### 📖 [立即開啟 EPUB → TXT 轉換網站](https://suyanali.github.io/EPUB-TXT-Converter/)

> 若連結暫時無法開啟，請稍後再試，網站需要先完成 GitHub Pages 部署。

## 如何使用？

1. **選擇 EPUB**：點選上傳區，或把 EPUB 檔案拖曳到網頁。可一次選擇多本書。
2. **選擇轉換設定**：一般情況使用預設值即可；需要簡轉繁時，再選擇文字轉換模式。
3. **按「開始轉換」**：網頁會逐本處理，並顯示成功或失敗的結果。
4. **下載檔案**：單本書下載 `.txt`；多本書預設打包為 `.zip`，解壓縮後就能取得各本 TXT。

整個轉換過程都在你的瀏覽器內進行，EPUB **不會上傳至網站伺服器**。

## 設定說明

### 文字轉換

| 選項 | 作用 |
|---|---|
| **不轉換（預設）** | 保留原書的簡體或繁體字詞。 |
| 簡體 → 台灣繁體 | 轉成台灣繁體字形，盡量保留原本用詞。 |
| 簡體 → 台灣繁體＋慣用詞 | 除了轉成繁體，也將部分用語換成台灣常見說法，例如「鼠标」→「滑鼠」。 |

### 段落排版

| 選項 | 作用 |
|---|---|
| **保留原始段落（預設）** | 保留 EPUB 的段落與章節區分，適合一般用途。 |
| 小說閱讀模式 | 段首縮排兩個全形空格，章節間留更多空行。 |
| 精簡模式 | 每段只換一行、減少空白行，方便搜尋與文字整理。 |

### 其他選項

| 選項 | 作用 |
|---|---|
| 保留章節標題（預設開啟） | 在 TXT 中保留各章標題。 |
| 移除 EPUB 導覽目錄（預設開啟） | 略過可以辨識的電子書導覽頁，避免目錄重複。 |
| 多本書打包 ZIP（預設開啟） | 將多本轉換後的 TXT 一起打包下載。 |

## 常見問題

**Q：轉換需要登入嗎？**  
A：不需要。檔案在你的裝置上處理。

**Q：為什麼無法轉換？**  
A：請確認檔案是 `.epub`。損壞、受 DRM 加密，或只有掃描圖片而沒有文字的電子書，可能無法成功轉出 TXT。

**Q：轉出的 TXT 為什麼沒有圖片？**  
A：TXT 是純文字格式，無法保留圖片、字型及原本的頁面排版。

**Q：手機可以用嗎？**  
A：可以，支援常見的手機、平板與桌面瀏覽器。大量或很大的 EPUB 可能受到裝置記憶體限制。

**Q：文字會變成亂碼嗎？**  
A：網站輸出 UTF-8 編碼的 TXT；如果閱讀軟體開啟時出現亂碼，請將閱讀軟體的文字編碼設定為 UTF-8。
